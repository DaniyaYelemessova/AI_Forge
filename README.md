# AI Chatbot Project

A step-by-step build of an AI chatbot, growing from a basic API call into RAG, agents, and MCP.

## Progress
- Stage 1: Basic chatbot (single message)
- Stage 2: Conversation memory
- Stage 3: Error handling

## Setup
1. Create a `.env` file with `ANTHROPIC_API_KEY=the-key`
2. `pip install -r requirements.txt`
3. Run `python chatbot.py`
